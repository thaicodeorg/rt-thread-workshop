## เปรียบเทียบ: Arduino vs RT-Thread

| คำสั่ง (Arduino) | คำสั่ง (RT-Thread) | คำอธิบาย |
|----------------|-------------------|---------|
| `Wire.begin()` | `rt_device_find("i2c1")` | เริ่มต้น I2C Bus |
| `Wire.beginTransmission(addr)` | `rt_i2c_transfer()` พร้อม `RT_I2C_WR` | ส่งข้อมูล |
| `Wire.requestFrom(addr, len)` | `rt_i2c_transfer()` พร้อม `RT_I2C_RD` | ร้องขอข้อมูล |
| `Wire.write(data)` | ใส่ใน `rt_i2c_msg.buf` | เขียนข้อมูล |
| `Wire.read()` | อ่านจาก `rt_i2c_msg.buf` | อ่านข้อมูล |
| `delay(1000)` | `rt_thread_mdelay(1000)` | หน่วงเวลา (RTOS-safe) |

!!! info "ความต่างสำคัญ"
    Arduino `Wire` library ครอบ I2C ไว้ทั้งหมด
    RT-Thread ใช้ **Device Framework** → ต้องหา device ก่อน ค่อย transfer

## สมมติฐาน

เซ็นเซอร์ที่ต่ออยู่:
- **SHT30** หรือ **BME280** หรือ **MPU6050**
- ต่อ SCL → P412
- ต่อ SDA → P411
- ต่อ VCC → 3.3V
- ต่อ GND → GND

!!! warning "ระวังแรงดัน"
    Vision-Board ใช้ **3.3V**
    อย่าต่อ sensor 5V โดยตรง → อาจทำให้ชิพเสีย

## Lab: อ่านค่า Sensor ด้วย RT-Thread

### ขั้นตอน 1: ตั้งค่า I2C ใน RASC

1. เปิด RA Smart Configurator
2. เพิ่ม I2C Master Stack
3. เลือก Pin SDA/SCL ให้ตรงกับบอร์ด
4. Generate

### ขั้นตอน 2: เปิด I2C Driver ใน RT-Thread Settings

- Using I2C Bus → ON
- Enable I2C hardware driver → ON

### ขั้นตอน 3: เขียน Code ใน hal_entry.c

```c
#include <rtthread.h>
#include <rtdevice.h>

#define SENSOR_I2C_BUS  "i2c1"
#define SENSOR_ADDR     (0x44 << 1)  // SHT30 address (แก้ตาม sensor ที่ใช้)

static struct rt_i2c_bus_device *i2c_bus;

// สำหรับ SHT30: อ่านค่าอุณหภูมิ
static rt_err_t sht30_read_temp(float *temp)
{
    struct rt_i2c_msg msgs[2];
    rt_uint8_t cmd[2] = {0x2C, 0x06};  // Command: measure temp
    rt_uint8_t buf[6];                  // 6 bytes response

    // Step 1: ส่งคำสั่งวัด
    msgs[0].addr   = SENSOR_ADDR;
    msgs[0].flags  = RT_I2C_WR;
    msgs[0].len    = 2;
    msgs[0].buf    = cmd;

    if (rt_i2c_transfer(i2c_bus, &msgs[0], 1) != 1) {
        return -RT_ERROR;
    }

    rt_thread_mdelay(20);  // รอ sensor วัด

    // Step 2: อ่านค่ากลับมา
    msgs[1].addr   = SENSOR_ADDR;
    msgs[1].flags  = RT_I2C_RD;
    msgs[1].len    = 6;
    msgs[1].buf    = buf;

    if (rt_i2c_transfer(i2c_bus, &msgs[1], 1) != 1) {
        return -RT_ERROR;
    }

    // แปลงค่า → อุณหภูมิ
    rt_uint16_t t_raw = (buf[0] << 8) | buf[1];
    *temp = -45 + 175 * ((float)t_raw / 65535);

    return RT_EOK;
}

void hal_entry(void)
{
    float temperature = 0;

    // หา I2C Bus
    i2c_bus = (struct rt_i2c_bus_device *)rt_device_find(SENSOR_I2C_BUS);
    if (!i2c_bus) {
        rt_kprintf("I2C bus not found!\n");
        return;
    }

    rt_kprintf("=== I2C Sensor Lab ===\n");

    while (1) {
        if (sht30_read_temp(&temperature) == RT_EOK) {
            rt_kprintf("Temperature: %.2f C\n", temperature);
        } else {
            rt_kprintf("Sensor read failed!\n");
        }
        rt_thread_mdelay(2000);
    }
}
```

### ตัวอย่าง Output

```
=== I2C Sensor Lab ===
Temperature: 25.34 C
Temperature: 25.41 C
Temperature: 25.38 C
```

## ใช้ Software Package แทน?

ถ้า sensor เคยมีคนเขียน Package ไว้แล้ว:

1. RT-Thread Settings → Software Packages
2. ค้นหา `sht3x` หรือ `bme280`
3. Add to Project
4. ใช้ได้เลย:

```c
#include <sht3x.h>
float temp, humi;
sht3x_read(&temp, &humi);
rt_kprintf("Temp: %.2f, Humi: %.2f\n", temp, humi);
```

!!! tip "ตรวจสอบ"
    ค้นหาใน [RT-Thread Packages](https://packages.rt-thread.org/) ว่ามี sensor ที่คุณใช้อยู่ไหม

## สรุป: ESP32 Arduino → RT-Thread

| แนวคิด | Arduino | RT-Thread |
|--------|---------|-----------|
| เริ่ม I2C | `Wire.begin()` | `rt_device_find("i2c1")` |
| ส่ง/รับ | `Wire.write()/read()` | `rt_i2c_transfer()` |
| Delay | `delay()` (busy-wait) | `rt_thread_mdelay()` (yield) |
| Library | `#include <Wire.h>` | `#include <rtdevice.h>` |
| Package | Arduino Libraries | RT-Thread Software Packages |

??? failure "แก้ปัญหาเบื้องต้น"
    **"I2C bus not found"**
    - ตรวจสอบ RASC ว่าเปิด I2C Master แล้ว
    - ตรวจสอบ RT-Thread Settings ว่าเปิด Using I2C Bus

    **"Sensor read failed"**
    - ตรวจสอบ Sensor Address (SHT30 = 0x44, BME280 = 0x76)
    - ตรวจสอบ Pull-up resistor บน SDA/SCL (ควรมี 4.7kΩ)
    - ตรวจสอบสายต่อ VCC/GND ถูกต้อง

    **"ค่าอุณหภูมิผิดปกติ"**
    - ตรวจสอบว่าใช้สูตรแปลงถูกต้องต่อ Sensor รุ่น
    - ตรวจสอบ CRC (ถ้า sensor ส่ง CRC มาด้วย)
