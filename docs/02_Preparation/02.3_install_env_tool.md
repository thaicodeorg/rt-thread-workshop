# ติดตั้ง ENV Tool v2.0.0

Env Tool คือเครื่องมือช่วยพัฒนาแบบบรรทัดคำสั่งที่ RT-Thread มอบให้อย่างเป็นทางการ ใช้สำหรับสร้างแวดล้อมการคอมไพล์ กำหนดค่าระบบแบบกราฟิก และจัดการแพ็กเกจซอฟต์แวร์ เป็นเครื่องมือพื้นฐานที่ขาดไม่ได้ในการพัฒนา RT-Thread ด้วยวิธีแบบดั้งเดิม (ไม่ใช้ Studio)


###  หน้าที่หลักสามประการ
1. การกำหนดค่าและการตัดทอนระบบ (menuconfig)
ป้อนคำสั่ง menuconfig ใน Env เพื่อเปิดอินเทอร์เฟซกราฟิก ซึ่งคุณสามารถเลือกหรือยกเลิกการเลือกฟังก์ชันเคอร์เนล คอมโพเนนต์ และไดรเวอร์ได้อย่างอิสระ หลังจากบันทึกแล้วจะสร้างไฟล์กำหนดค่า rtconfig.h โดยอัตโนมัติ โดยไม่ต้องแก้ไขด้วยมือ

2. การจัดการแพ็กเกจซอฟต์แวร์ (pkgs)
จัดการแพ็กเกจซอฟต์แวร์ออนไลน์ผ่านคำสั่ง pkgs ตัวอย่างเช่น pkgs --update จะดาวน์โหลดหรืออัปเดตแพ็กเกจที่เลือกใน menuconfig โดยอัตโนมัติ และลบแพ็กเกจที่ไม่ได้เลือกแล้ว นี่คือวิธีหลักในการติดตั้งไลบรารี เช่น lwIP, FreeModbus ใน RT-Thread

3. การสร้างโปรเจกต์ (scons)
ใช้คำสั่ง scons --target=mdk5 (หรือ iar, vsc) เพื่อสร้างโปรเจกต์ที่กำหนดค่าเสร็จแล้วเป็นไฟล์โปรเจกต์ของ IDE เป้าหมาย เพื่อให้สามารถคอมไพล์และดีบักใน Keil, IAR หรือ VS Code ได้

### ทดสอบการ Build source ด้วย เครื่องมือ scons
- หลังจาก Fork และ Clone source code มาเรียบร้อย ด้วย Git protocol ไม่ใช่ http เปลี่ยนชื่อ thaicodeorg เป็นชื่อ repo ของคุณ และเพิ่ม upstream ชี้ไปยัง project หลักให้เรียบร้อย
```
cd C:\Renesas\
git clone git@github.com:thaicodeorg/rt-thread.git
cd rt-thread
git remote add upstream git@github.com:RT-Thread/rt-thread.git
git fetch upstream
git checkout master
git merge upstream/master
git push origin master
```

``C:\Renesas\rt-thread\bsp\renesas\ra8d1-vision-board``
