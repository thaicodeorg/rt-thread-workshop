# ติดตั้ง Env Tool

<span class="md-tag">Optional</span> <span class="md-tag">10 นาที</span>

## Env Tool คืออะไร

**Env Tool** = ชุดเครื่องมือ command line สำหรับ RT-Thread

- ใช้แทน RT-Thread Studio บางงาน
- มี `scons` (build tool), Git, MinGW
- เหมาะสำหรับคนถนัด command line

!!! info "ต้องติดตั้งไหม?"
    - **ถ้าใช้ RT-Thread Studio** → ไม่จำเป็นต้องติดตั้ง Env Tool (Studio มี build system ในตัว)
    - **ถ้าอยากเรียนรู้ build ผ่าน command line** → ติดตั้งเพื่อความรู้

---

## วิธีติดตั้ง

1. ดาวน์โหลด Env Tool จาก [RT-Thread GitHub](https://github.com/RT-Thread/env)

2. แตกไฟล์ไว้ใน `C:\Renesas\env`

3. เปิด `env.bat` หรือใช้ MinGW terminal

```bash
cd C:\Renesas\env
env.bat
```

4. ทดสอบ:

```bash
scons --version
```

!!! success "Checkpoint"
    ✅ `scons` รันได้ใน terminal
    ✅ ไม่ต้องใช้ถ้าทำงานผ่าน Studio
