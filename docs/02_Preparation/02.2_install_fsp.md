# ติดตั้ง FSP

<span class="md-tag">Prerequisite</span> <span class="md-tag">10 นาที</span>

## FSP คืออะไร

**FSP (Flexible Software Package)** = ชุดซอฟต์แวร์จาก Renesas สำหรับชิป RA8D1

- มีไดรเวอร์ GPIO, UART, I2C, SPI, Timer
- มีเครื่องมือ **RA Smart Configurator** ตั้งค่าฮาร์ดแวร์แบบกราฟิก
- Studio จะใช้ FSP ตั้งค่าพินและเปิดใช้งาน peripheral

---

## วิธีติดตั้ง

### ขั้นตอน

1. ไปที่ [Renesas เว็บไซต์](https://www.renesas.com/us/en/products/software-tools/software-os-mw-sd/flexible-software-package-fsp)

2. ดาวน์โหลด FSP เวอร์ชันที่ตรงกับ BSP ใน Workshop (ปกติเป็น FSP v5.1.0 หรือ v5.3.0)

3. ติดตั้งในโฟลเดอร์ `C:\Renesas\RA\`

   ```
   C:\Renesas\RA\sc_v2023-10_fsp_v5.1.0
   ```

   !!! success "Checkpoint"
       ✅ เห็นโฟลเดอร์ `sc_v2023-10_fsp_v5.1.0`
       ✅ มีไฟล์ `rasc.exe` อยู่ในโฟลเดอร์นั้น

---

## วิธีใช้ FSP ใน RT-Thread Studio

1. เปิดโปรเจกต์ใน Studio

2. Double-click **RA Smart Configurator** ใน Project Explorer

3. Studio จะถามว่า FSP อยู่ที่ไหน → เลือกโฟลเดอร์ที่ติดตั้งไว้

   ```
   C:\Renesas\RA\sc_v2023-10_fsp_v5.1.0
   ```

   !!! tip "ถ้าเลือกแล้วไม่ขึ้น"
       ตรวจสอบว่าชื่อโฟลเดอร์ตรงกับที่ Studio คาดหวัง (ดูจาก Error Message)

---

## สรุป

- FSP ติดตั้งครั้งเดียว ใช้ได้ทุกโปรเจกต์
- ถ้ามีเวอร์ชันใหม่ ไม่ต้องรีบอัปเดตถ้าบอร์ดยังใช้เวอร์ชันเก่าอยู่
