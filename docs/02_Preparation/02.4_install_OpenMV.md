## ส่วนที่ 1: ติดตั้ง OpenMV IDE

3. ติดตั้งแบบปกติ

!!! success "Checkpoint"
    ✅ เปิด OpenMV IDE ได้
    ✅ เห็นหน้าต่าง Code Editor และ Terminal

## ส่วนที่ 2: ติดตั้ง Keil MDK (สำหรับ Workshop OpenMV firmware)

### ทำไมต้อง Keil MDK?
- ใช้ Build OpenMV Firmware สำหรับบอร์ด Vision-Board
- บางโปรเจกต์ต้องใช้ Keil แทน RT-Thread Studio

### วิธีติดตั้ง

1. ไปที่ [keil.com/download](https://www.keil.com/download/product/)

2. เลือก **MDK-ARM**

3. ติดตั้งที่ `C:\Renesas\Keil_v5`

4. ลงทะเบียน License (Free version จำกัด 32KB)

!!! tip "ทางเลือก"
    ถ้าไม่ต้องการ Build Firmware เอง → ใช้ Firmware ที่มีอยู่แล้วใน repo → ไม่ต้องติดตั้ง Keil

---

## ส่วนที่ 3: เพิ่ม Keil ใน Environment Path

1. ค้นหา "env" ใน Windows Search

2. เลือก **Environment Variables**

3. ใน **Path** → เพิ่ม:
   - `C:\Renesas\Keil_v5\UV4`
   - `C:\Renesas\Keil_v5\ARM\bin`

```
uv4
```

!!! success "Checkpoint"
    ✅ พิมพ์ `uv4` ใน Command Prompt → เปิด Keil ได้
