# ติดตั้ง RT-Thread IDE

<span class="md-tag">Windows</span> <span class="md-tag">15–20 นาที</span>

RT-Thread Studio คือ Integrated Development Environment (IDE) แบบครบวงจรและฟรี ที่ออกแบบมาเฉพาะสำหรับการพัฒนา IoT ด้วยระบบปฏิบัติการ RT-Thread จุดเด่นคือช่วยลดความยุ่งยากในการพัฒนา embedded system โดยรวมการสร้างโปรเจกต์ การตั้งค่าแบบกราฟิก การเขียนโค้ด การดีบัก และการจัดการแพ็กเกจไว้ในเครื่องมือเดียว

!!! tip "เคล็ดลับก่อนเริ่ม"
    สร้าง Folder ชื่อ `Renesas` ที่ Drive `C:` เพื่อจัดเก็บซอฟต์แวร์ทั้งหมดในที่เดียว ทำให้สะดวกในการพัฒนา

## ขั้นตอน 1: ดาวน์โหลดตัวติดตั้ง

1. เปิด Browser ไปยัง [https://www.rt-thread.io/](https://www.rt-thread.io/)

   ![](./images/1_rt-thread-web.png){ width="600" }

2. กดไปยังเมนู **Download > Studio** เพื่อเข้าสู่หน้า Download

   ![](./images/2_rt-thread-download.png){ width="600" }

3. Link จะนำไปยัง GitHub [RT-Thread/rt-thread](https://github.com/RT-Thread/rt-thread) — ไปยังเมนู **Release** ทางด้านขวามือ

   ![](./images/3_rt-thread-release.png){ width="600" }

!!! note "ไฟล์ที่ต้องดาวน์โหลด"
    ให้ Download `RT-Thread-Studio-setup-x86_64-latest.exe` มายังเครื่องให้เรียบร้อย


4. โครงสร้าง Folder ที่จะใช้ใน Workshop:

   ![](./images/4_folder-structure.png){ width="400" }

## ขั้นตอน 2: ติดตั้งโปรแกรม

1. สร้าง folder `Renesas` ใน Drive `C:`

   ![](./images/4_folder-structure1.png){ width="400" }

2. Double Click `RT-Thread-Studio-setup-x86_64-latest.exe`

   ![](./images/5_rt-thread-install-1.png){ width="500" }

3. กด **Next**

   ![](./images/5_rt-thread-install-2.png){ width="500" }

4. เลือกยอมรับ **I Accept Agreement** กด **Next** เปลี่ยนตำแหน่งติดตั้งจาก `D:` → `C:\Renesas` แล้วกด **OK**

   ![](./images/5_rt-thread-install-3.png){ width="500" }

5. ตรวจสอบตำแหน่งติดตั้งให้ถูกต้อง แล้วกด **Next**

   ![](./images/5_rt-thread-install-4.png){ width="500" }
   ![](./images/5_rt-thread-install-5.png){ width="500" }
   ![](./images/5_rt-thread-install-6.png){ width="500" }

6. กด **Install** รอประมาณ 2–3 นาที

   ![](./images/5_rt-thread-install-7.png){ width="500" }
   ![](./images/5_rt-thread-install-8.png){ width="500" }

7. กด **Finish** เพื่อ Launch Studio

## ขั้นตอน 3: เปิดโปรแกรมครั้งแรก

1. Load Program

   ![](./images/5_rt-thread-install-9.png){ width="500" }

2. จะพบกับหน้า Welcome พร้อม Link ไปยัง Resource ต่างๆ

   ![](./images/5_rt-thread-install-10.png){ width="600" }

## ติดตั้ง SDK ด้วย SDK Manager

SDK Manager ใน RT-Thread Studio คือเครื่องมือจัดการซอฟต์แวร์สำหรับดาวน์โหลดและอัปเดตแพ็กเกจซอร์สโค้ดแบบออนไลน์

### หน้าที่หลัก

- ดาวน์โหลดและอัปเดตออนไลน์ตาม Version
- จัดการทรัพยากรในเครื่อง (จัดเก็บใน `repo\Extract`)

### ขั้นตอนการเรียกใช้ SDK

1. กด shortcut **SDK Manager** ในตำแหน่งที่ 1

   ![](./images/5_rt-thread-install-11.png){ width="500" }

2. RT-Thread SDK Manager จะถูกเปิดขึ้นมา เลื่อน Scroll เพื่อเลือก SDK ที่ต้องการ

   ![](./images/rt-thread-manager.png){ width="600" }

### BSP (Board Support Package)

คือชุดโค้ดที่เชื่อมระบบปฏิบัติการเข้ากับฮาร์ดแวร์ของบอร์ดพัฒนาเฉพาะรุ่น ทำหน้าที่เป็น "สะพานเชื่อม" ระหว่างซอฟต์แวร์และฮาร์ดแวร์

**หน้าที่หลัก:**

- [x] เริ่มต้นฮาร์ดแวร์: รับผิดชอบการเริ่มต้นรีจิสเตอร์ภายในของชิป ตั้งค่า RAM เริ่มต้นฮีปหน่วยความจำ
- [x] ให้ไดรเวอร์และอินเทอร์เฟซ: UART, GPIO, Ethernet, LCD, Pinmux
- [x] ทำให้การพอร์ตง่ายขึ้น: BSP กว่า 200 รายการพร้อม README

#### เลือก Vision Board BSP, Toolchain, Debugger

1. **Board_Support_Packages > Renesas > Vision-Board > 1.3.0**

   ![](./images/5_rt-thread-sdk-vision.png){ width="500" }

2. **ToolChain_Support_Packages > GNU_Tools_for_ARM_Embedded > 13.3**

   ![](./images/5_rt-thread-sdk-toolcain.png){ width="500" }

3. **Debugger_Support_Packages > PyOCD > 0.3.1 และ 0.2.7**

   ![](./images/5_rt-thread-sdk-pyocd.png){ width="500" }

4. กด **Install**

   ![](./images/5_rt-thread-install-package1.png){ width="500" }

รอจนกระทั้งติดตั้งเสร็จสิ้น
