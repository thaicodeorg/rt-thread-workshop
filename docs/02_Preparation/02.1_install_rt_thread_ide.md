# ติดตั้ง RT-Thread IDE

RT-Thread Studio คือ Integrated Development Environment (IDE) แบบครบวงจรและฟรี ที่ออกแบบมาเฉพาะสำหรับการพัฒนา IoT ด้วยระบบปฏิบัติการ RT-Thread จุดเด่นคือช่วยลดความยุ่งยากในการพัฒนา embedded system โดยรวมการสร้างโปรเจกต์ การตั้งค่าแบบกราฟิก การเขียนโค้ด การดีบัก และการจัดการแพ็กเกจไว้ในเครื่องมือเดียว

## ติดตั้ง SDK ด้วย SDK Manager   "คลัง Software"
SDK Manager ใน RT-Thread Studio คือเครื่องมือจัดการซอฟต์แวร์ที่ใช้สำหรับดาวน์โหลดและอัปเดตแพ็กเกจซอร์สโค้ดของ RT-Thread แบบออนไลน์ หน้าที่หลักคือช่วยให้คุณได้รับเวอร์ชันเสถียรหรือเวอร์ชันล่าสุดของโค้ดระบบปฏิบัติการ RT-Thread ได้อย่างรวดเร็ว เพื่อใช้ในโครงการพัฒนา

### หน้าหลักของ SDK
- ดาวน์โหลดและอัปเดตออนไลน์ ตาม Version: สามารถดาวน์โหลดแพ็กเกจโค้ดเวอร์ชันเสถียรของ RT-Thread ได้โดยตรงผ่านเครือข่าย และยังสามารถอัปเดตเป็นซอร์สโค้ดเวอร์ชันล่าสุดได้ด้วย
- จัดการทรัพยากรในเครื่อง: ไฟล์ที่ดาวน์โหลดมักจะถูกจัดเก็บไว้ในไดเรกทอรีทรัพยากรของ IDE (เช่น repo\Extract ใต้ไดเรกทอรีติดตั้ง) เพื่อให้โครงการอ้างอิงถึงได้

### ขั้นตอนการเรียกใชั SDK
- ไปที่ยัง shortcut menu ในตำแหน่ง 1 คือ SDK Manager  กด ได้เลย
![](./images/5_rt-thread-install-11.png)
- RT-Thread SDK manager จะถูกเปิดขึ้นมา เพื่อให้เราสามารถ ติดตั้ง SDK ตามต้องการ โดย สรุป เราจะทำการติดตั้ง โดยสามารถใช้ mouse scroll เลือกเพื่อเลือก SDK ที่ต้องการ โดยเป้าหมายของเรา จะเพิ่มเติม Hardware ที่ต้องการพัฒนา โดยเลือกผ่าน BSP
![](./images/rt-thread-manager.png)

### BSP (Board Support Package) หรือ แพ็กเกจสนับสนุนระดับบอร์ด ใน RT-Thread  

คือชุดโค้ดที่เชื่อมระบบปฏิบัติการเข้ากับฮาร์ดแวร์ของบอร์ดพัฒนาเฉพาะรุ่น ทำหน้าที่เป็น "สะพานเชื่อม" ระหว่างสองส่วนนี้ เพื่อให้ระบบปฏิบัติการสามารถทำงานบนบอร์ดนั้นได้

#### หน้าที่หลักของ BSP
BSP จะห่อหุ้มรายละเอียดฮาร์ดแวร์เฉพาะของบอร์ดนั้นไว้ ช่วยให้นักพัฒนาสามารถเพ่งความสนใจไปที่การพัฒนาแอปพลิเคชันได้ โดยงานหลักๆ ได้แก่:
- เริ่มต้นฮาร์ดแวร์: รับผิดชอบการเริ่มต้นรีจิสเตอร์ภายในของชิป การตั้งค่าจังหวะการทำงานของ RAM ตลอดจนการเริ่มต้นฮีปหน่วยความจำแบบไดนามิก เพื่อสร้างสภาพแวดล้อมพื้นฐานสำหรับการรันระบบปฏิบัติการ
- ให้ไดรเวอร์และอินเทอร์เฟซ: มีไดรเวอร์สำหรับอุปกรณ์ต่อพ่วงบนบอร์ด (เช่น UART, GPIO, อีเทอร์เน็ต, LCD, เป็นต้น) รวมถึงการตั้งค่าพินมัลติเพล็กซ์ (Pinmux) แอปพลิเคชันสามารถควบคุมฮาร์ดแวร์ได้โดยการเรียกใช้อินเทอร์เฟซอุปกรณ์มาตรฐานที่ RT-Thread ให้มา
- ทำให้การพอร์ตง่ายขึ้น: RT-Thread ได้จัดเตรียม BSP ไว้เกือบ 200 รายการสำหรับบอร์ดพัฒนาต่างๆ โดยทั่วไปจะมีโครงสร้างไดเรกทอรีที่คล้ายคลึงกันและมีไฟล์ README ประกอบ นักพัฒนาสามารถอ้างอิง BSP เหล่านี้เพื่อทำความเข้าใจอย่างรวดเร็วหรือดำเนินการพอร์ตกับบอร์ดใหม่
