    ติดตั้ง RT-Thread IDE¶

    Windows 15–20 นาที

    RT-Thread Studio คือ Integrated Development Environment (IDE) แบบครบวงจรและฟรี ที่ออกแบบมาเฉพาะสำหรับการพัฒนา IoT ด้วยระบบปฏิบัติการ RT-Thread จุดเด่นคือช่วยลดความยุ่งยากในการพัฒนา embedded system โดยรวมการสร้างโปรเจกต์ การตั้งค่าแบบกราฟิก การเขียนโค้ด การดีบัก และการจัดการแพ็กเกจไว้ในเครื่องมือเดียว

    เคล็ดลับก่อนเริ่ม

    สร้าง Folder ชื่อ Renesas ที่ Drive C: เพื่อจัดเก็บซอฟต์แวร์ทั้งหมดในที่เดียว ทำให้สะดวกในการพัฒนา

    ขั้นตอน 1: ดาวน์โหลดตัวติดตั้ง¶

    1. เปิด Browser ไปยัง https://www.rt-thread.io/

    1. กดไปยังเมนู Download > Studio เพื่อเข้าสู่หน้า Download

    1. Link จะนำไปยัง GitHub RT-Thread/rt-thread — ไปยังเมนู Release ทางด้านขวามือ

    ไฟล์ที่ต้องดาวน์โหลด

    ให้ Download RT-Thread-Studio-setup-x86_64-latest.exe มายังเครื่องให้เรียบร้อย

    1. โครงสร้าง Folder ที่จะใช้ใน Workshop:

    ขั้นตอน 2: ติดตั้งโปรแกรม¶

    1. สร้าง folder Renesas ใน Drive C:

    1. Double Click RT-Thread-Studio-setup-x86_64-latest.exe

    1. กด Next

    1. เลือกยอมรับ I Accept Agreement กด Next เปลี่ยนตำแหน่งติดตั้งจาก D: → C:\Renesas แล้วกด OK

    1. ตรวจสอบตำแหน่งติดตั้งให้ถูกต้อง แล้วกด Next

    1. กด Install รอประมาณ 2–3 นาที

    1. กด Finish เพื่อ Launch Studio

    ขั้นตอน 3: เปิดโปรแกรมครั้งแรก¶

    1. Load Program

    1. จะพบกับหน้า Welcome พร้อม Link ไปยัง Resource ต่างๆ

    ติดตั้ง SDK ด้วย SDK Manager¶

    SDK Manager ใน RT-Thread Studio คือเครื่องมือจัดการซอฟต์แวร์สำหรับดาวน์โหลดและอัปเดตแพ็กเกจซอร์สโค้ดแบบออนไลน์

    หน้าที่หลัก¶

    • ดาวน์โหลดและอัปเดตออนไลน์ตาม Version
    • จัดการทรัพยากรในเครื่อง (จัดเก็บใน repo\Extract)

    ขั้นตอนการเรียกใช้ SDK¶

    1. กด shortcut SDK Manager ในตำแหน่งที่ 1

    1. RT-Thread SDK Manager จะถูกเปิดขึ้นมา เลื่อน Scroll เพื่อเลือก SDK ที่ต้องการ

    BSP (Board Support Package)¶

    คือชุดโค้ดที่เชื่อมระบบปฏิบัติการเข้ากับฮาร์ดแวร์ของบอร์ดพัฒนาเฉพาะรุ่น ทำหน้าที่เป็น "สะพานเชื่อม" ระหว่างซอฟต์แวร์และฮาร์ดแวร์

    หน้าที่หลัก:

    • เริ่มต้นฮาร์ดแวร์: รับผิดชอบการเริ่มต้นรีจิสเตอร์ภายในของชิป ตั้งค่า RAM เริ่มต้นฮีปหน่วยความจำ
    • ให้ไดรเวอร์และอินเทอร์เฟซ: UART, GPIO, Ethernet, LCD, Pinmux
    • ทำให้การพอร์ตง่ายขึ้น: BSP กว่า 200 รายการพร้อม README

    เลือก Vision Board BSP, Toolchain, Debugger¶

    1. Board_Support_Packages > Renesas > Vision-Board > 1.3.0

    1. ToolChain_Support_Packages > GNU_Tools_for_ARM_Embedded > 13.3

    1. Debugger_Support_Packages > PyOCD > 0.3.1 และ 0.2.7

    1. กด Install

    รอจนกระทั้งติดตั้งเสร็จสิ้น

    ตรวจสอบ Version ของ RT-Thread¶

    ลองเปิด GitHub RT-Thread

    • นักพัฒนาสามารถเลือก Version Source Code ที่ต้องการได้ในส่วน Menu RT-Thread Source Code ซึ่งจะตรงกับ Tag ของ GitHub

    Note

    ใน Workshop เรายังไม่เปลี่ยน Version แต่หากท่านใดต้องการทดสอบก็ใช้ RT-Thread SDK Manager ติดตั้งได้เช่นกัน
