    Workshop 6: OpenMV¶

    Advanced 60 นาที

    ก่อนเริ่ม Lab¶

    • ติดตั้ง Keil MDK เรียบร้อย
    • ติดตั้ง Git เรียบร้อย
    • มีบอร์ด Vision พร้อมสาย USB-DBG และ USB-OTG

    เมื่อทำเสร็จ คุณจะได้¶

    • Build OpenMV Firmware ลงบอร์ด RA8D1 ได้
    • ใช้ OpenMV IDE เชื่อมต่อกล้องได้
    • รัน Python Script ให้กล้องตรวจจับวัตถุได้

    OpenMV คืออะไร¶

    OpenMV = แพลตฟอร์ม Computer Vision สำหรับ Microcontroller

    • เขียนโค้ดด้วย MicroPython
    • ใช้กล้องบนบอร์ด Vision-Board (หรือต่อกล้องภายนอก)
    • รองรับ: ตรวจจับใบหน้า, สี, QR Code, อ่านตัวเลข, Machine Learning
    ┌─────────────────────────┐
│    OpenMV IDE (PC)      │
│  - เขียน Python Script   │
│  - ดูภาพ Real-time        │
└───────────┬─────────────┘
            │ USB
┌───────────▼─────────────┐
│   Vision-Board (RA8D1)  │
│  - OpenMV Firmware        │
│  - Camera Module          │
│  - Python Runtime         │
└─────────────────────────┘

    Lab 6.1: Clone OpenMV Project¶

    ขั้นตอน¶

    1. เปิด Git Bash หรือ CMD

    2. Clone project ไปที่ C:\Renesas:

    cd C:\Renesas
git clone https://github.com/RT-Thread-Studio/sdk-bsp-ra8d1-vision-board.git

    !!! success "Checkpoint 6.1" ✅ มีโฟลเดอร์ C:\Renesas\sdk-bsp-ra8d1-vision-board\projects\vision_board_openmv

    Lab 6.2: ตรวจสอบ Environment¶

    ขั้นตอน¶

    1. ตรวจสอบว่า Keil MDK ติดตั้งที่ C:\Renesas\Keil_v5\UV4\UV4.exe

    1. เพิ่ม UV4 ไปยัง Windows Environment Path:

    2. ค้นหา "env" ใน Windows Search

    3. เลือก Environment Variables
    4. เพิ่ม C:\Renesas\Keil_v5\UV4 ใน PATH

    !!! success "Checkpoint 6.2" ✅ พิมพ์ uv4 ใน Command Prompt แล้วเปิด Keil ได้

    Lab 6.3: Build OpenMV Firmware¶

    ขั้นตอน¶

    1. เปิด Project ใน RT-Thread Studio:
    File → Import → Existing Projects into Workspace
เลือก: C:\Renesas\sdk-bsp-ra8d1-vision-board\projects\vision_board_openmv
    1. Build Project กด 🔨

    !!! success "Checkpoint 6.3" ✅ Build Success (อาจใช้เวลา 2-5 นาที)

    Lab 6.4: Flash Firmware และเชื่อมต่อ OpenMV IDE¶

    ขั้นตอน¶

    1. Flash firmware ลงบอร์ด (ใช้ USB-DBG)

    2. เสียบสาย USB-OTG เข้ากับคอมพิวเตอร์

    !!! warning "สำคัญ" USB-OTG ใช้สำหรับ OpenMV IDE (ส่งภาพ) USB-DBG ใช้สำหรับดีบักและ Flash

    1. เปิด OpenMV IDE

    2. กดปุ่ม Connect (มุมซ้ายล่าง)

    !!! success "Checkpoint 6.4" ✅ OpenMV IDE เชื่อมต่อกับกล้องได้ ✅ เห็นภาพ Real-time ในหน้าต่าง IDE

    import sensor
import image
import time

sensor.reset()
sensor.set_pixformat(sensor.RGB565)
sensor.set_framesize(sensor.QVGA)
sensor.skip_frames(time=2000)

while True:
    img = sensor.snapshot()
    # ตรวจจับสีแดง
    for blob in img.find_blobs([(30, 100, 15, 127, 15, 127)]):
        img.draw_rectangle(blob.rect())
        img.draw_cross(blob.cx(), blob.cy())

    เตรียมไป Workshop 8¶

    Workshop 8 จะใช้ TensorFlow Lite บน OpenMV เพื่อ ตรวจจับใบหน้า (Face Detection)

    แก้ปัญหาเบื้องต้น

    "OpenMV IDE หา Camera ไม่เจอ" - ตรวจสอบว่าเสียบสาย USB-OTG (ไม่ใช่ USB-DBG) - ลองกด Reset บนบอร์ดแล้ว Connect ใหม่

    "Build Error: หา Keil ไม่เจอ" - ตรวจสอบว่าเพิ่ม C:\Renesas\Keil_v5\UV4 ใน Environment PATH - รีสตาร์ท RT-Thread Studio

    "ภาพใน IDE เป็นสีดำ" - ตรวจสอบว่า Camera Module เสียบแน่น - ลองเปลี่ยนสาย USB-OTG
